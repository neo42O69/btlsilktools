# BTL Silk Tools
## ABOUT
Gives tools that act as silk touch with some gimmicks
### Trowel
The trowel acts as a silk touch shovel with half durability. Unlike the silk touch shovel, it can harvest farmland and paths.
### Chisel
The chisel acts a silk touch pickaxe with half durability. Unlike the silk touch pickaxe, it can't harvest grasses.
## WARNING
Currently there's an experience dupe where you can mine ores with the chisel, get the experience from them, and place them back. This is not intentional and is planned to be fixed.
