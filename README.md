# BTL Silk Tools
_"Adds silk touch tools without enchantments. Just craft and silk!"_
## ABOUT
Gives tools that act as silk touch with some gimmicks
### Trowel
The trowel acts as a silk touch shovel with half durability. Unlike the silk touch shovel, it can harvest farmland and paths, and it turns paths into dirt.



<img width="480" height="232" alt="trowel" src="https://github.com/user-attachments/assets/1ba00ad2-bb2c-4f4e-872a-ce456bf12b98" />

### Chisel
The chisel acts a silk touch pickaxe with half durability. Unlike the silk touch pickaxe, it can't harvest grasses.

<img width="480" height="232" alt="chisel" src="https://github.com/user-attachments/assets/51d20d71-e061-4dac-a811-1607c3b0b4a0" />

### Sieve (Versions 2 and above)
The sieve will always get flint from gravel. Other tools can't get flint anymore.

## WARNING
Versions under 1 have an XP dupe where you can mine ores, get their xp, then place and mine them again. This was fixed in version 1.
